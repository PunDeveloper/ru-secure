# RuSecure | Android

**Пользуйтесь российскими сайтами через Яндекс Браузер, а остальными — в своём любимом.**

## Проблема

Иностранные браузеры перестают принимать российские корневые сертификаты, поэтому часть рунета открывается без защищённого соединения или вообще не открывается.

[Подробнее на Хабре](https://habr.com/ru/news/1066306/)

Варианты обхода:

1. **Поставить Яндекс Браузер по умолчанию** — работает, но теряется любимый браузер (синхронизация, расширения, пароли).
2. **Установить корневой сертификат Минцифры в систему** — ⚠️ **не рекомендую**. Браузеры могут его игнорировать, а главное: сертификат даёт его владельцу право подписывать ЛЮБОЙ сайт в интернете (в том числе google.com), что открывает дорогу к MITM-атакам.
3. **RuSecure** — приложение-маршрутизатор ссылок, которое решает проблему без смены браузера и без установки корневого сертификата.

## Как это работает

RuSecure перехватывает ссылки и открывает их в нужном браузере:

- **Российские сайты** → Яндекс Браузер
- **Остальные сайты** → браузер по вашему выбору (Chrome, Firefox, Brave, и т.д.)

Список российских сайтов собирается автоматически из проекта [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community) (категория `category-ru`) и обновляется раз в сутки. Можно вручную добавить свои сайты или исключения.

## Установка

**Через Obtainium:**

1. Откройте [Obtainium](https://github.com/ImranR98/Obtainium).
2. Нажмите `+` → `GitHub` → введите `PunDeveloper/ru-secure`.
3. Установите.

**Вручную:** скачайте APK со страницы [Releases](https://github.com/PunDeveloper/ru-secure/releases).

## Настройка

После установки назначьте RuSecure **браузером по умолчанию** — только так приложение сможет перехватывать ссылки.

## Настройки и списки

По умолчанию приложение работает «из коробки», но в настройках можно:

- включить/отключить использование списка geosite (`category-ru`)
- обновить список вручную
- включить/отключить автоматическое определение зон `.ru` и `.рф`
- выбрать конкретные браузеры для российских и остальных сайтов

### Два списка сайтов

| Список | Назначение |
|---|---|
| Российские сайты | Принудительно открываются в Яндекс Браузере (даже если не попадают под geosite) |
| Исключения | Принудительно открываются в другом браузере (даже если есть в geosite) |

Галочка рядом с полем ввода определяет, в какой список попадёт сайт. Домен извлекается автоматически — можно вставлять полный URL.

## Ограничения

RuSecure перехватывает ссылки, которые приложения передают системе через `Intent.ACTION_VIEW`. **Не перехватываются:**

- встроенные WebView внутри приложений
- Chrome Custom Tabs
- встроенные браузеры мессенджеров (Telegram, Signal, Discord)
- ссылки, открытые внутри другого браузера

Это системное ограничение Android, обойти его без root невозможно.
